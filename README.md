# Определение ориентации кропнутого текста

Решение представлено в `solution.ipynb`. Для воспроизведения кода без повторного обучения модели необходима папка с тестовой выборкой  `test/images/`, еще необходимо установить `requirements.txt`. Блокнот создаст тот же `submission.csv`. 

Была использована модель PP-LCNet_x0_25_textline_ori, экстрактор признаков был оставлен без изменений, а классификатор дообучен в PyTorch. Обучено 1281 значение головы, в ONNX хранится около 242746 значений весов. Train выборка содержала 100000 кропов, 50% из которых реальных HierText и 50% синтетических. Размер ONNX составил 1.02 МБ, скорость 449 изображений/с. 

## Обучение и валидация

Для повторного обучения необходимо включить `RUN_TRAINING=True` в блокноте и выполните ячейки по порядку. Обучение идёт на CPU с seed 100. Недостающие аннотации и фотографии HierText скачиваются автоматически. Если они уже лежат в `data/hiertext/`,то код использует локальные файлы. Шрифты DejaVu находятся в `assets/fonts/`, словарь в `assets/dictionaries/`. При запуске с `RUN_TRAINING=False` скачивание и обучение не выполняются.

Исходные фотографии из реальных данных разделены до создания кропов и пар 0/180 градусов, поэтому одна фотография не попадает в разные части выборки. Validation использовалась для выбора эпохи, calibration — для настройки вероятностей, selection — для выбора усреднения предсказаний с повёрнутым изображением. Holdout оставался для итоговой проверки. Тестовые изображения в обучении и выборе настроек не использовались.

На holdout Brier Score = 0.04290, то есть основная метрика `1 − Brier Score = 0.95710`, accuracy = 94%. Это результаты на собственной отложенной выборке, состоящей наполовину из синтетических данных и наполовину реальных, а не на тесте с неизвестными метками.

## Использованные материалы

- [Официальная PP-LCNet_x0_25_textline_ori](https://huggingface.co/PaddlePaddle/PP-LCNet_x0_25_textline_ori_onnx) — модель взятая за основу решения
- [HierText](https://github.com/google-research-datasets/hiertext) — фотографии реального текста
- Шрифты DejaVu — `assets/fonts/`; лицензия приложена в той же папке.
